# Code of Conduct

We want this to be a place where people can contribute without being harassed or talked down to.

## Expected

- Be respectful and assume good intent.
- Give specific, kind, useful feedback. Criticise code, not people.
- Accept that maintainers make the final call on design and scope.
- Help newcomers.

## Not accepted

- Harassment, insults, personal attacks, or discrimination of any kind.
- Posting other people's private information, including real resumes, profiles or application answers.
- Spam, advertising, or repeated pushing after a decision has been made.
- Using this project to build tools that submit false applications, evade a site's anti-abuse systems or mass-target employers.

## Enforcement

Maintainers may edit or remove comments, close or lock issues and pull requests, and block accounts. To report a problem, email the maintainer address listed on the maintainer's GitHub profile or open a private report through the repository's Security tab.

This text is adapted from the Contributor Covenant, version 2.1.
